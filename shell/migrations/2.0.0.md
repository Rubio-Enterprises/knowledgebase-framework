# Migrating this knowledgebase to Knowledgebase Framework v2

v2 removes `status: deprecated`: a document that no longer holds is deleted, not kept as a stub,
and a commit fails if any document links to a file that doesn't exist. Follow these steps in this
knowledgebase's folder.

1. **Point the Hooks at v2.** In the `lefthook.yml` that wires this knowledgebase (this folder's own,
   or the containing repository's), the knowledgebase-framework remote reads `ref: v2` and the
   fetched-Hooks check names `knowledgebase-framework-v2`. Copier updated a root knowledgebase's
   file already. Otherwise change both from `v1` (if that `lefthook.yml` is generated, change its
   source instead) and run `lefthook install`.
2. **Retire every deprecated document.** For each file that `grep -l '^status: deprecated' docs/*.md`
   lists:
   1. Find the document that replaces it, usually the one its opening paragraph links to.
   2. Move any fact that still holds and that the replacement lacks into the replacement.
   3. Point every link to it in `docs/` at the replacement, or remove the link when nothing
      replaces it.
   4. Delete it, and add a line under today's heading in `docs/log.md`:
      `* **Retired**: old-name.md, replaced by [New title](new-name.md).`
3. **Fix the remaining broken links.** Run `lefthook run kb-check`. For each `links to …, which
   doesn't exist` it reports, point the link at the right document or remove it.

Done when `grep -l '^status: deprecated' docs/*.md` prints nothing and `lefthook run kb-check`
passes. Then delete this file and commit everything in one commit.
