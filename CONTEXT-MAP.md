# Context Map

The Knowledgebase Framework's domain model, in two contexts.

## Contexts

- [Framework](./CONTEXT.md): how the framework is packaged and delivered to knowledgebases
- [Knowledgebase](./docs/knowledgebase/CONTEXT.md): the language the framework teaches the people
  and agents who write in a knowledgebase

## Relationships

- **Framework → Knowledgebase**: the Framework delivers the Knowledgebase context's vocabulary into
  every knowledgebase, defining each term where it is used in the managed block of `AGENTS.md`
- **Shared term**: Knowledgebase means the same thing in both contexts
